- Get the device name connect to type "wifi". 
`nmcli device`

- Then disconnect the device 
`nmcli device disconnect <DEVICE NAME>`

- Create a random MAC Address 
`sudo ip link set dev <DEVICE NAME> address 02:xx:xx:xx:xx:xx`
	-- Replace the `xx` pairs with any random two-digit hex values from `00` to `ff`, e.g., `02:4a:8f:1c:93:b2`—keep `02` at the start so it's a valid locally administered unicast address

Disconnect manually from wifi then connect again.
