### Step 1) Basic Chat

- This step we create the bridge between the model and the folder. 
- It was converted the chat.go from the github to .py
- The idea was to keep the history of the conversation and test if the Agent remembers some information in the history. 

**Question:** The information provided in this agent is kept and shared with other users of the library or it is restrained to my local computer? 

**Claude Answer:**

`chat.py → localhost:11434 (Ollama server) → model on your disk`

- **The `ollama` Python library** is only a client. It sends HTTP requests to the Ollama server on your own machine (`localhost:11434`) and has no servers of its own to send data to.
- **The model** (`qwen2.5-coder:7b`) runs entirely on your hardware. Your prompts and its answers are processed there.
- **Other users of the library** each run their own copy on their own machine. There is no shared memory or account between them.
- **The history** (`conversation` in our code) is a Python list in your script's memory. It disappears when you close the program, unless we choose to save it to a file later.

To get the host:

- echo $OLLAMA_HOST
- **Empty:** default, so `127.0.0.1:11434` (local only)
