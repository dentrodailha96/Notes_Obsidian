**Base:** https://github.com/ghuntley/how-to-build-a-coding-agent?ref=ghuntley.com
**Goal:** Replicate this agent with Python and Ollama. The idea is to replicate everything open source and understand the steps of an AI Agent . 
**Support**: Claude AI 

### Steps of the project

| Step | File                | Development                                         | Concepts to be learn                                                         | Evaluation Check                                                      |
| ---- | ------------------- | --------------------------------------------------- | ---------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| 0    | set up              | Ollama, tool-capable model, python environment      | reading models locally                                                       | the sanity check, command prints a greeting                           |
| 1    | chat.py             | terminal, chatbot with memory of the conversation   | the message list, the input, inference, print loop                           | Ask for a name and confirm if it remember it.                         |
| 2    | read.py             | first tool: read_file                               | tool schemas, tool_calls, sending role: "tool" results back, the agent loop  | "What's in riddle.txt?" and it reads the file and answer it.          |
| 3    | list_files.py       | Second tool: list_files                             | Multiple tools, a tool registry, chaining tools.                             | "What files are here? then "Read the Python ones"                     |
| 4    | bash_tool.py        | Third tool: bash (shell commands)                   | Running subprocesses capturing stdout/ stderr, returning errors to the model | "Run git status" and it runs the command and summarizes the output.   |
| 5    | edit_tool.py        | Fourth tool: edit_file                              | Safe file editing (replace text, create files), validation                   | "Create hello.py that prints hi" and the file exists and runs.        |
| 6    | code_search_tool.py | Fifth tool: code_search using ripgrep               | Pattern search, large outputs, limiting results                              | Find all TODO comments, and it returns the matches with file and line |
| 7    | --verbose           | Polish flag, config for model/host, error, handling | CLI arguments, environment variables                                         | you can switch models without editing code                            |
| 8    | customization       | Extras of your choice                               | Custom tools, memory, across sessions, web UI                                | open                                                                  |

| Important Commands                | Function                                        |
| --------------------------------- | ----------------------------------------------- |
| ollama --version                  | check the version running                       |
| ollama pull < model of interest > | add the model of interest                       |
| ollama list                       | all the models installed locally                |
| ollama rm < model of interest >   | delete the model to make more space in the disk |
| ollama run < model of interest >  | chat with it directly in the terminal           |

This command runs this function: 
```
import ollama

response = ollama.chat(
    model='qwen2.5-coder:7b',
    messages=[{'role': 'user', 'content': 'Say hi'}]
)

print(response['message']['content'])
```
