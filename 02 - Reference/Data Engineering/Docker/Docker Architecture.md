#### RESTful API 

- One that uses standard HTTP request types such as GET, POST, DELETE and others to perform functions that usually correspond to those intended by HTTP's designers. 
#### Daemon
- Is a server that receives requests and returns responses from the client using the HTTP protocol. 
- Take care from the image and containers behind the scenes.
