P.s.: The main difference between environment and shell variables is the operating system passes all of yours shell's environment variables to programs that the shell runs, whereas shell variables cannot be accessed in the commands that you run. 

- Environment variables:
	- export {variable name}
	- **printenv** - return all the environment variables 

### PATH
- environment variables that contains the command path. A list of directories that the shell searches when trying to locate a command. 
- When we run a command, these are the directories that the shell look up for the command/program. 
- Add a path in $PATH:
	- PATH=dir:$PATH
- The order of the paths is the order that the shell looks up.
