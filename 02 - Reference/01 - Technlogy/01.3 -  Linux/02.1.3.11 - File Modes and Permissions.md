#### Anatomy of File Permission:
	 -(Type) -> if it is dash, means a regular file binary or text.
	rw- (User Permission) -> 
	rw- (group permissions)
	 r-- (Other permissions )

#### Files permission:
- r : readable
- w : writable
- x : executable
- - : nothing 

Files permissions are shown by the command: "ls -l"

#### Modifying permissions
- **chmod** : change permissions

#### Standard files I/O
- Stands for File Input/Output, in other words, is the process of carrying out operations on a file on a disk or other forms of storage.
