#### Anatomy of File Permission:
	 -(Type) -> if it is dash, means a regular file binary or text.
	rw- (User Permission) -> 
	rw- (group permissions)
	 r-- (Other permissions )

#### Files permission:
- r : readable
- w : writable
- x : executable
- - : nothing 

#### Modifying permissions
- **chmod** : change permissions
