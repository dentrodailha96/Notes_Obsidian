### Commands Basic commands Linux
- **echo** : print info in the screen if the string is typed between **''** . 
- **cat**: outputs the contents of one of more files or another source of input.
	- stdin = standard input
	- stdout = standard output 
- **ls**: list directories contents.
	- ls -l (detailed)
	- ls -F (file type info)
- **cp**: copies files 
		`cp {source file} {destination file or to other directory}`
- **mv**: movie files
		`mv {file 1} {renamed file or move to another directory}` 
- **touch**: create a file, if the file named already exists, therefore touch doesn't change the file, but it does update the file's modification timestamp.
	- touch {file name}
- **rm**: deletes or remove a file, once it is removed it cannot be recovered. 

### Directory Navigation
- **..** : parent directory
- **.**: current directory
- **mkdir**: create a directory
- **rmdir**: removes a directory
	- It only deletes if it is empty.
	- Force a delete >> `rm -r` (*r means recursive, which this repeats the action until everything inside of the directory is affected* ).
- echo * : returns everything existing in the directory. 
	- at* = expands to all filenames that starts with at
	- *at = expands to all file names that ends with at.
	- * at  *=  expands to all filenames that contain at.

- **man**: manual
- **more**: pagenate a text in the screen.
    > **enter** for one line at the time
    > **space** for one page at the time
    > h for help, how to use more the action.

- less:
  > **g** : go to BOF (begin of file)  
  > **G** : go to EOF (end of file)
  > **/{string}** : look up for string in the file
  > **n/N** : next or previous of appearance
  > h for help, how to use more the action.

- **one tab** : automatic complete.
- **two tabs** : all the options for that search.
- **history** : all the comments submitted.
  > !{number command in history}: repeat the command.
- **clear** or **ctrl + L**: clean the cmd.
- **!{command}** or **!!** : last time the command ran or last command ran.

* **readlink {file name } -f** : find the path of a file in bashcd 

### Concepts

- **Shell** : works as a small programming environment, which runs commands like programs in Windows. 
	- **Shell scrips**, are text files that contains a sequence of shell commands (ex.: up.sh or .bat files)

- Users in Linux:
	 `id -u` 
	- *If returns 1000 > it is a regular human user , if it return 0, it is a root user.*
