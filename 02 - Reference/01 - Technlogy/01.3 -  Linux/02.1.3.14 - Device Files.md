- Are files that exist as an interface for your system to interact with the hardware. 
- They are located at '/dev/'
- Using the command 'ls -l' in '/dev/', it return all the devices and their respective type.


| Name      | Meaning                                                                                                            |
| --------- | ------------------------------------------------------------------------------------------------------------------ |
| Block     | Devices that stores buffered data as blocks.                                                                       |
| character | Works with data streams, example: keyboard, devices that transfer the data one by one.                             |
| pipe      | similar to character files, but with another process at the other end of the I/O stream instead of a kernel drive. |
| socket    | Interprocess communication, their represent the UNIX domain.                                                       |

#### Relevant paths for Device info
- */dev/* - summary about the device
- */sys/devices* - provides the full hardware attributes 

#### Types of devices:


| Name                | Path         | Command   | Function                                               |
| ------------------- | ------------ | --------- | ------------------------------------------------------ |
| Hard Disk           | /dev/sd*     | lsscsi    | list the devices on the system.                        |
| Virtual Disk        | /dev/xvd*    |           | the virtualized machines.                              |
| Non-Volatile Memory | /dev/nvme*   | nvme list | list of devices that talk to some solid state storage. |
| Mapper              | /dev/dm-*    |           |                                                        |
| CD and DVD          | /dev/sr*     |           |                                                        |
| PATH hard disk      | /dev/hd*     |           |                                                        |
| Terminals           | /dev/tty*    |           |                                                        |
| Serial Ports        | /dev/ttyUSB* |           |                                                        |
| Parallel Ports      | /dev/lp0     |           | bidirectional parallel ports                           |
| Audio Devices       | /dev/snd/*   |           |                                                        |
