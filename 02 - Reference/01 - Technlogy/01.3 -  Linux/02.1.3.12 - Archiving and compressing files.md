- **gzip**: (.gz)
	- compress: gzip {file name}
	- uncompress: gunzip {file name}.gz
- **tar** : zip multiple files into an archive. 
	- pack tar file: tar cvf {archive name}.tar {file1} {file2} {file3}
	- c = create mode
	- v = verboses
	- f = file option
	- unpack tar file: tar xvf {archive name}.tar 
		- before unpack a tar is important to read the metadata (substitute x by t).

### What is a .tar?
 - computer format to bundle multiple files and entire directory structures into a single file without losing metadata as permissions and ownership.
